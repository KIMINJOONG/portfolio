### 2. 포토카드 이미지 검색
**씨에스트레이딩 | 어드민용 이미지 검색 기능**

스캔하거나 촬영한 포토카드와 유사한 상품을 찾는 검색 기능을 개발했습니다.

- 얼굴 특징과 CLIP 이미지 특징을 결합해 Qdrant의 약 63만 개 이미지 벡터 검색
- 얼굴이 없는 카드의 검색 문제를 분석하고, 특징별 가중치와 점수 계산 방식 조정
- OpenCV로 촬영 이미지의 카드 영역을 검출하고 원근 보정
- 유사하지만 다른 카드의 오인식을 고려해 자동 확정 대신 운영자 검수 방식 적용
- 중복 후보를 자동 병합하지 않고 검수 대상으로 분리
- FastAPI와 GPU 기반 임베딩 생성 및 동시 실행 수 제한
- 이미지 URL 기반 ID로 재색인 시 기존 벡터가 갱신되도록 구성

**기술**: Python, FastAPI, OpenCV, CLIP, Qdrant, GPU

## 개발할 때 중요하게 생각하는 것

### 운영에서 실패할 수 있다는 전제
외부 API 호출은 실패하거나 지연될 수 있고, 웹훅은 중복으로 도착할 수 있습니다.
재시도, 중복 요청 방지, 처리 상태 기록, 재처리 경로를 함께 고려합니다.

### 데이터 정합성과 트랜잭션 범위
주문과 재고처럼 함께 변경되어야 하는 데이터는 트랜잭션으로 묶고,
외부 API를 기다리는 작업은 DB 트랜잭션과 분리합니다.

### 자동화와 사람의 판단 사이의 균형
이미지 검색처럼 오인식 가능성이 있는 기능은 무조건 자동 확정하기보다,
후보와 검수 흐름을 제공해 실제 운영에 맞는 방식으로 설계합니다.

### 제품 전체에 대한 책임
프론트엔드와 백엔드의 경계를 넘어 앱, 배포, 운영 도구까지 연결해
서비스가 실제로 동작하고 지속적으로 운영될 수 있도록 개발합니다.
